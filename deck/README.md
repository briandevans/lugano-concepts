# Royal AI Group — Founding SAFE deck

14 slides. 1920×1080. Dark royal + cream paper. Confidential footer on every slide.

## Present

Open `index.html` in a browser. Arrow keys, space, and swipe change slides.

```
npx --yes serve deck
```

Then visit `/` and use `#s01` … `#s14`.

## Export PDF + PNGs

```
cd deck
npx --yes playwright install chromium
node export.mjs
```

Writes `export/slide-01.png` … `slide-14.png` and `export/Royal_AI_Group_Founding_SAFE.pdf`.
